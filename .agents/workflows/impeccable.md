# /impeccable

Directs the agent using Impeccable UI/UX design skills.

## Usage

- `/impeccable init` — Capture durable product truth in PRODUCT.md
- `/impeccable document` — Generate DESIGN.md from existing project code
- `/impeccable audit [target]` — Technical quality checks (a11y, perf, responsive)
- `/impeccable critique [target]` — UX design review with heuristic scoring
- `/impeccable polish [target]` — Final visual and interaction cleanup pass
- `/impeccable bolder [target]` — Amplify safe, bland, or generic designs
- `/impeccable quieter [target]` — Tone down aggressive or busy styling
- `/impeccable typeset [target]` — Improve typography hierarchy and fonts
- `/impeccable layout [target]` — Fix spacing, alignment, and rhythm
- `/impeccable clarify [target]` — Improve UX copy and labels
- `/impeccable adapt [target]` — Multi-device and responsive refinement
- `/impeccable harden [target]` — Error states, edge cases, and i18n

## Execution

Load the Impeccable skill at `.agents/skills/impeccable/SKILL.md` (or `.agent/skills/impeccable/SKILL.md`) and consult its reference playbook for the requested sub-command.
